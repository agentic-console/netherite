# Netherite AI Assistant

A Chrome extension that leverages Chrome's built-in Gemini Nano AI to automatically fill web forms with intelligent, context-aware responses.

## Features

- **AI-Powered Form Filling**: Uses Chrome's built-in Gemini Nano for intelligent form completion
- **Smart Field Detection**: Automatically identifies and categorizes form fields
- **Speech-to-Text Input**: Voice input support for hands-free interaction  
- **Document Integration**: Upload and reference documents for context-aware responses
- **Modern UI**: Clean, professional interface with custom branding
- **Advanced Field Support**: Handles text inputs, dropdowns, radio buttons, and checkboxes with semantic matching

## Installation

1. Clone this repository
2. Install dependencies: `npm install`
3. Build the extension: `npm run build`
4. Load the `dist` folder as an unpacked extension in Chrome Developer Mode

## Requirements

- Chrome browser with Gemini Nano AI support
- Chrome Developer Mode enabled for extension installation

## Usage

1. Navigate to any webpage with forms
2. Click the Netherite extension icon to open the floating toolbar
3. Use the scanner to analyze form fields
4. Interact with the AI assistant to fill forms intelligently
5. Use voice input for hands-free operation
